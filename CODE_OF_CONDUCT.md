# Code of Conduct

## 1. Purpose

The Orderly project is committed to maintaining a professional, respectful, and collaborative environment for all contributors, maintainers, and reviewers.

---

## 2. Expected Standards

All participants are expected to uphold the following standards:

- **Professional Communication:** Communicate respectfully and constructively during code reviews, architectural discussions, and issue triage.
- **Objective Feedback:** Focus code review comments on architecture, design patterns, security, and correctness.
- **Inclusive Environment:** Treat every contributor with respect regardless of background, identity, or level of experience.
- **Confidentiality & Security:** Protect proprietary source code, credentials, and internal technical documentation from unauthorized disclosure.

---

## 3. Unacceptable Behavior

The following behaviors are strictly prohibited:

- Harassment, discrimination, derogatory commentary, or offensive language in any project space.
- Deliberate trolling, inflammatory arguments, or disruptive communication.
- Publishing private information, secrets, or internal project data without authorization.
- Any conduct that compromises repository integrity, code security, or participant safety.

---

## 4. Enforcement & Reporting

Project maintainers are responsible for clarifying and enforcing our standards of acceptable behavior. Instances of abusive, harassing, or unacceptable behavior should be reported directly to the repository maintainer (`@rajesh-kayal-dev`) via private communication channels.

Maintainers have the right and responsibility to remove, edit, or reject comments, commits, code, and issues that do not align with this Code of Conduct.
